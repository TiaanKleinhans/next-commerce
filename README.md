# Next.js Project

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

---

## 🚀 Getting Started 🚀

Run the development server:

```bash
npm run dev
```


🧰 Tech Stack 🧰

Next.js — eReact framework for building server-rendered and static web apps
Node.js v20.19.5 — Runtime environment
TypeScript — Type safety 

Tailwind CSS + SCSS — Styling 
ESLint — Syntax and code quality checker
Prisma — ORM (acts as a type-safe database client)

Docker — Containerization
tsx — TypeScript executor for fast dev workflows
shadcn/ui — Reusable, customizable component system built on Tailwind and Radix
